# Free Mine Contracts

Смарт-контракты инвестиционного фонда для EVM.

Пользователи вносят доллары и получают токены Фонда, представляющие их долю
в Фонде. Капиталом управляет владелец Фонда, который может размещать активы
во внешних DeFi-протоколах.

Вывод не является мгновенным: пользователи создают заявки, а владелец
Фонда назначает цену выкупа. Финальное решение о продаже токенов Фонда
принимает пользователь.

Система также предусматривает аварийный механизм восстановления управления
в случае смерти владельца.

## Архитектура

Код смарт-контрактов с комментариями представлен в директории `contracts`.
Эти файлы и являются самым подробным описанием архитектуры децентрализованной
составляющей системы.
