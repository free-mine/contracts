# Free Mine Contracts

Смарт-контракты инвестиционного фонда для EVM.

Пользователи вносят Dollar token и получают FundToken, представляющий их долю
в Фонде. Капиталом управляет владелец Фонда, который может размещать активы
во внешних DeFi-протоколах. Покупка FundToken
и вывод средств происходят через Gate.

Вывод не является мгновенным: пользователь создаёт заявку,
после чего владелец Фонда освобождает необходимую ликвидность
и завершает соответствующую стадию вывода. Система также предусматривает
аварийный механизм восстановления управления в случае смерти владельца.
