# Архитектура

Система состоит из трёх развёртываемых контрактов и внешнего долларового ERC20.

```text
Owner / Admins
      │
      ▼
    Fund
      │ owns
      ▼
    Gate
      │ owns
      ▼
 FundToken

Users ──────► Gate
```

## Компоненты

### Fund

Хранит и управляет капиталом Фонда. Через него владелец
и администраторы выполняют операции с активами и управляют `Gate`.

`Fund` является владельцем `Gate`.

### Gate

Основная точка взаимодействия пользователей с системой.

`Gate`:

* продаёт `FundToken` за долларовый токен;
* управляет ценой покупки;
* принимает заявки на вывод;
* проводит вывод по стадиям.

`Gate` является владельцем `FundToken`
и поэтому контролирует его выпуск и сжигание.

### FundToken

ERC20-токен, представляющий долю пользователя в Фонде.
Новые токены выпускаются при покупке через `Gate`
и сжигаются при завершённом выводе.

### Dollar token

Внешний ERC20, используемый для покупки и вывода.
Он не является частью системы контрактов.

Dollar token должен быть обычным ERC20 с предсказуемой семантикой
`transfer` и `transferFrom`. Токены с fee-on-transfer, rebasing,
изменяемым балансом или другой нестандартной логикой передачи
не поддерживаются: система предполагает, что отправленное
и полученное количество токенов совпадает.

## Потоки средств

При покупке:

```text
User ── dollars ──► Fund
User ◄─ FundToken ─ Gate
```

При выводе `FundToken` временно передаются в `Gate`. После завершения стадии
`Fund` предоставляет `Gate` необходимое количество долларов. Затем
пользователь либо получает доллары, либо отменяет заявку и получает токены
обратно за вычетом комиссии.

В обычном состоянии основной капитал находится в `Fund`;
`Gate` хранит только активы, необходимые для обработки заявок на вывод.
